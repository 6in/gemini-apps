Skills Cheat Sheet

Matt Pocock's "Skills For Real Engineers" — 全スキル一覧

Engineering /skills/engineering/

日常のコード作業で使うスキル群。

スキルコマンド用途セットアップ
diagnose /diagnose バグ・パフォーマンス劣化の体系的な診断ループ（再現→最小化→仮説→計測→修正→回帰テスト） soft
grill-with-docs /grill-with-docs プランをドメインモデルに照らして徹底的にグリル。CONTEXT.md / ADR をインラインで更新 soft
improve-codebase-architecture /improve-codebase-architecture CONTEXT.md と ADR に基づいてコードベースの深化機会を発見 soft
prototype /prototype 使い捨てプロトタイプ作成。ターミナルアプリ or 複数UIバリエーション切り替え -
setup-matt-pocock-skills /setup-matt-pocock-skills リポジトリ別設定の初期化（Issue tracker, triage ラベル, ドメインドキュメント構成） 最初に実行
tdd /tdd Red-Green-Refactor ループによるテスト駆動開発。垂直スライスで1テストずつ soft
to-issues /to-issues プラン/スペック/PRD を垂直スライスの独立 Issue に分割 hard
to-prd /to-prd 現在の会話コンテキストから PRD を生成し Issue tracker に公開 hard
triage /triage Issue のトリアージ（状態マシン駆動のラベル付けワークフロー） hard
zoom-out /zoom-out 不慣れなコード領域の全体像・上位文脈を説明させる soft
セットアップ列: hard = /setup-matt-pocock-skills が必須  |  soft = なくても動くが精度向上  |  - = 依存なし

Productivity /skills/productivity/

コード以外の汎用ワークフローツール。

スキルコマンド用途
caveman /caveman 超圧縮コミュニケーションモード。トークン使用量 ~75% 削減
grill-me /grill-me プラン/設計について1問ずつ徹底的にインタビュー。意思決定ツリーの全分岐を解決
handoff /handoff 会話を引き継ぎドキュメントに圧縮。別エージェントが続行可能に
write-a-skill /write-a-skill 新しいスキルの作成（構造・段階的開示・バンドルリソース付き）

In-Progress /skills/in-progress/ 未リリース

Quick Reference — よく使う組み合わせ

新機能を作る前に: /grill-with-docs → /to-prd → /to-issues → /tdd
バグを直す: /diagnose → /tdd
設計を壁打ちしたい: /grill-me （コード不要） or /grill-with-docs （コード付き）
コードベースの健康診断: /improve-codebase-architecture
別セッションに引き継ぐ: /handoff
トークン節約: /caveman
